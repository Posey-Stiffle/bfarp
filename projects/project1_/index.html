Project 1

My brushes have a variety in what kind of lines it can paint on the canvas with two of the brushes being animated.
Since my drawing program is more focused on making character illustrations, it has brushes more suitable
for that purpose. Below is a reference for my brushes and what keys to press in order to use them.

[1] Default brush [2] Square path brush [3] Circle path brush [4] Spray brush
[5] Stringy brush [6] Square tool [7] Circle tool [8] Snake brush
[9] Trazo brush [0] Eraser [h] Trazo brush outliner [s] Save canvas
