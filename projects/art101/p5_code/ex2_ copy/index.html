Project 4

An image must be uploaded first before proceeding to the next screen. While this was made to be used by illustrative artists, photos may be uploaded as well. However, since photos were not made to be used for this filter, results may vary.

.png and .jpg files are accepted, .png files with transparent backgrounds also work as well.
When a filter has "riso" in front of the name, it means its a filter from the p5.riso library. A filter with "FIP" in front of the name is a filter from the "Filter Image Processing" library. The "grain" filter is from the p5.grain library.
Sound effects were added to make the experience more immersive.

The help button explains each filter and what it does.
